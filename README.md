# 字幕时间轴修复器

本地运行的字幕时间轴修复工具（React + TypeScript + Vite）。导入 SRT 字幕与本地视频后，可在播放器下方的时间轴上直接拖动字幕块调整起止时间，对照自动生成的音频波形精确定位人声，实时检测时间重叠、起止倒置、时长过短等问题，修复完成后导出标准 SRT。

## 功能

- 📄 **导入 SRT / 本地视频**：视频仅通过 `URL.createObjectURL` 在本地播放，不上传任何数据
- 🌊 **音频波形轨道**：导入视频后在浏览器内用 Web Audio API 解码音轨，按固定时间桶提取正/负峰值，绘制在标尺与字幕块之间，与刻度、播放头共用同一时间坐标；缩放 / 横向滚动时只渲染可视区；解码失败可关闭提示，不影响字幕编辑；波形仅驻留内存，切换视频自动释放
- 🧱 **时间轴编辑**：播放器下方按时间轴展示字幕块
  - 拖动块体：整体平移该条字幕
  - 拖动左右两端手柄：分别调整开始 / 结束时间
  - 点击标尺或轨道空白处：移动播放头并联动视频跳转
  - 双击字幕块：跳转到该字幕开始时间
- 🔗 **连锁移动**：开启后，平移某条字幕时其后所有字幕保持相对间隔同步平移
- 🚦 **实时问题检测**（字幕块与右侧面板同步高亮）
  - 红色：时间重叠
  - 紫色（斜纹）：起止倒置（结束 ≤ 开始）
  - 黄色：时长短于 500ms
- ↶↷ **撤销 / 重做**：拖动、删除等操作均可回退
- ⚓ **双锚点漂移校准**：整稿时间随播放进度线性漂移（开头差 0.5s、结尾差 3s 之类）时，选择两条锚点字幕并填写各自与视频对齐的目标开始时间，系统按「锚点 A 之前统一偏移 → 两锚点间按原始开始时间线性插值 → 锚点 B 之后统一偏移」平移整批字幕，所有字幕时长不变；锚点须按当前时间先后排列且目标时间递增，否则禁用应用并提示原因；应用前预览受影响条数与最大偏移，整批作为一次撤销/重做
- 📚 **修订稿合并**：当前字幕已加载时，可再导入一份 SRT 作为修订稿（不替换当前时间轴）。系统按「文本相似度 0.6 + 时间区间 IoU 0.4」加权打分，用动态规划求保持顺序的一对一最大总分匹配，侧栏预览每对的当前/修订文本、得分及两侧未匹配项；应用时仅把已匹配的修订文本写回当前字幕（保留 id、序号与时间），整批可一次撤销/重做
- 🔇 **静音吸附**（音频波形就绪后可用）：选择一段连续字幕区间并设置峰值阈值、最短静音长度、最大吸附距离、字幕最小时长后，系统以每个波形桶的 `max(|min|, |max|)` 判定静音桶，合并连续命中桶得到静音段并取其中点；为每条字幕的原起止位置及最大距离内的静音中点生成候选，用动态规划在「保持条目顺序、每条时长达标、互不重叠」约束下，依次最大化吸附边界数、最小化总位移（同分取新时间序列字典序较小者）；侧栏逐条预览原/新时间与对应的静音段，无可行方案时禁用应用，整批作为一次撤销/重做
- 📏 **断行重排**：选择一段连续字幕区间并设置每行最大字素数；系统忽略 `i`、`b`、`u`、`font` 标签的占位宽度，以 Unicode 字素簇计数，在不改变可见文字顺序与标签内容的前提下把每条字幕排成一行或两行；候选断点不得使行首出现闭合标点或行尾出现起始标点，在均不超限的方案中依次选择最大行长最小、两行长度差最小、断点最靠前者；无可行方案的条目标出原因且不修改，侧栏逐条预览原文与重排结果并可只勾选可行项应用，整批写入作为一次撤销/重做
- 💾 **导出修复后的 SRT**：按开始时间排序并重新编号

## 快速开始（Docker，单条命令）

```bash
docker compose up --build
```

启动后在浏览器访问：

> **http://localhost:8080**

（容器内 Nginx 监听 80 端口，Compose 映射到宿主机 **8080** 端口；如需修改，调整 `docker-compose.yml` 中的 `ports`。）

停止服务：

```bash
docker compose down
```

## 使用说明

1. 点击 **导入 SRT** 选择字幕文件（或先点 **加载示例** 体验，示例故意包含三类问题）。
2. 点击 **导入视频** 关联本地视频（可选，不导入也能编辑时间轴）；导入后自动解码音轨，在标尺与字幕块之间显示音频波形。
3. 在时间轴上拖动字幕块或其两端手柄修复问题；右侧「问题检测」面板实时刷新，点击条目可跳转定位。
4. 需要整体后移/前移某段字幕时，打开 **连锁移动** 再拖动即可。
5. 需要套用另一份修订后的 SRT 文本时，点击工具栏 **修订稿合并** 打开右侧侧栏（详见下文）。
6. 整稿时间随播放进度逐渐漂移时，点击工具栏 **漂移校准** 打开双锚点校准侧栏（详见下文）。
7. 已导入视频且波形解码完成（时间轴显示波形）后，可点击工具栏 **静音吸附**，把所选字幕的起止边界对齐到语句间的静音中点（详见下文）。
8. 需要统一排版每行长度时，点击工具栏 **断行重排**，按每行最大字素数把所选区间字幕排成一行或两行（详见下文）。
9. 修复完成后点击 **导出修复后 SRT** 下载文件（文件名自动加 `.fixed` 后缀）。

### 双锚点漂移校准侧栏

入口：工具栏的 **⚓ 漂移校准** 按钮（需先导入当前字幕，否则按钮禁用；与修订稿合并侧栏互斥）。

适用于整稿字幕与视频之间存在「渐进式漂移」的场景：开头只差零点几秒，越往后差得越多，单点整体平移无法对齐。

1. 分别在 **锚点 A**、**锚点 B** 的下拉框中各选一条字幕（按当前开始时间排序列出，含序号、时间与文本预览）；目标时间留空时会自动预填该字幕的当前开始时间，便于微调。
2. 为每条锚点填写它与视频对齐后的**目标开始时间**，支持 `83.5`（秒）、`02:05`（分:秒）、`00:01:23,500`（时:分:秒,毫秒）等格式；也可以先把视频播放到对齐位置，再点 **⏱ 播放头** 一键填入当前播放头时间。
3. 系统据此为每条字幕计算偏移：
   - 锚点 A 之前（含）：统一使用锚点 A 的偏移；
   - 两锚点之间：按**原始开始时间**在两个锚点偏移间线性插值；
   - 锚点 B 之后（含）：统一使用锚点 B 的偏移；
   - 所有字幕**时长保持不变**（起止时间同步平移）。
4. 锚点须按当前时间先后排列（A 的开始时间早于 B），目标开始时间也须递增；不满足、锚点缺失、目标时间无法解析、平移后有字幕越过 0 点或无需校准时，**应用** 按钮禁用并显示具体原因。
5. 应用前侧栏实时预览 **受影响条数** 与 **最大偏移**；点 **应用校准** 后整批平移作为**一次撤销/重做**操作（`Ctrl/Cmd+Z` 即可整体回退）。重新导入字幕会自动清空锚点表单。

### 修订稿合并侧栏

入口：工具栏的 **📚 修订稿合并** 按钮（需先导入当前字幕，否则按钮禁用）。

1. 在侧栏点 **导入修订稿** 选择另一份 SRT。修订稿只作为文本来源，**不会替换当前字幕的时间轴、id 与序号**。
2. 两侧文本先转小写、去首尾空白并折叠连续空白，再按 Unicode 字符数计算 Levenshtein 编辑距离：
   - 文本得分 = `1 − 编辑距离 / max(两侧字符数, 1)`
   - 时间得分 = 两条字幕毫秒区间的 IoU（交并比），无有效交集（含区间倒置、仅端点相接）时为 0
   - 综合得分 = `0.6 × 文本 + 0.4 × 时间`，仅保留综合得分 ≥ **0.45** 的候选对
3. 用动态规划在「匹配 / 跳过修订稿 / 跳过当前稿」三种转移中求**保持顺序的一对一最大总分匹配**；同分时依次优先：匹配 → 跳过修订稿 → 跳过当前稿。
4. 侧栏预览每对匹配的当前/修订文本、综合得分（悬停可看文本、时间分项）与时间；下方分组列出两侧的未匹配条目（点击当前稿条目可跳转定位）。
5. 点 **应用合并** 后，仅把已匹配条目的修订文本写回当前字幕，**id、序号、起止时间全部保留**，修订稿中未匹配的条目不写入；整批写入作为**一次撤销/重做**操作（`Ctrl/Cmd+Z` 即可整体回退）。重新导入当前字幕会自动清空修订稿。

### 静音吸附侧栏

入口：工具栏的 **🔇 静音吸附** 按钮。**仅在音频波形就绪后可用**（未导入视频、波形解码中 / 失败时按钮禁用）；与其他侧栏互斥，波形被关闭或切换视频时侧栏自动收起。

用于把字幕的起止边界快速对齐到说话之间的停顿处：

1. 先 **导入视频** 并等待时间轴上出现音频波形；再点击 **静音吸附** 打开侧栏。
2. 在 **起点字幕**、**终点字幕** 两个下拉框中选择一段**连续字幕区间**（按当前开始时间排序列出；两端顺序可互换，也可以是同一条）。
3. 设置四个参数：
   - **峰值阈值（0–1，默认 0.02）**：每个波形桶计算 `max(|负峰|, |正峰|)`，严格小于阈值的桶判为静音桶；环境噪声大可适当调大。
   - **最短静音长度（ms，默认 250）**：连续静音桶合并成段，短于此长度的段直接丢弃，避免把字缝误当停顿。
   - **最大吸附距离（ms，默认 1500）**：只有距原边界在此范围内的静音中点才作为候选。
   - **字幕最小时长（ms，默认 500）**：吸附后每条字幕时长不得短于此值。
4. 静音段取**连续命中桶合并区间的中点**作为吸附落点；每个字幕边界的候选 = 原位置 + 距离内的全部静音中点（静音中点恰等于原时间时计入吸附）。
5. 系统用**动态规划**在下列约束下选方案：保持条目先后顺序、相邻条目互不重叠（允许端点相接）、每条时长不短于最小时长；优劣依次为 **① 吸附边界数最多 → ② 总位移（所有边界绝对位移之和）最小 → ③ 仍同分时新时间序列字典序较小者**。
6. 侧栏顶部汇总区间条数、检测到的静音段数、吸附边界数 / 总位移 / 变动条数；下方逐条预览 **原时间 → 新时间** 以及开始 / 结束边界是「保持原位」还是吸附到了哪个静音中点（含该静音段时长），点击条目可跳转定位。**无可行方案（或参数 / 区间无效）时应用按钮禁用并提示原因**。
7. 点 **应用吸附** 后仅修改所选区间字幕的起止时间，其余字幕不动；整批作为**一次撤销/重做**操作（`Ctrl/Cmd+Z` 即可整体回退）。重新导入字幕会自动重置区间与参数。

### 断行重排侧栏

入口：工具栏的 **📏 断行重排** 按钮（需先导入当前字幕，否则按钮禁用；与其他侧栏互斥）。

用于把字幕文本统一排成不超过指定宽度的一行或两行（标签不占宽）：

1. 在 **起点字幕**、**终点字幕** 两个下拉框中选择一段**连续字幕区间**（按当前开始时间排序列出；两端顺序可互换，也可以是同一条）。
2. 填写 **每行最大字素数**（不小于 1 的整数，默认 20）；计数与排版规则：
   - `<i>`、`<b>`、`<u>`、`<font …>` 及其闭合标签（大小写不敏感、可带属性）识别为标签，**不占行宽**并原样保留在字素序列中；其余标签（如 `<marquee>`）按可见文字计宽；
   - 可见文字按 **Unicode 字素簇（grapheme cluster）** 计数，带变音记号的字母（`café`）、ZWJ 表情（`👨‍👩‍👧`）等组合序列各算 1 个字素；
   - 原有的换行先去除、各物理行按可见顺序首尾相接（行内空白原样保留，不折叠也不新增），重排只在字素边界之间插入至多一个换行；标签内容与可见文字顺序绝不改变。
3. **候选断点约束**：断入行首（跳过标签与边缘空白）不得是**闭合标点**（闭括号 / 闭引号 / 句末与句读符号等），断出行尾不得是**起始标点**（各类开括号 / 开引号）。
4. **方案选择**：单行本身不超限时优先一行；需要两行时，仅在两行行长均不超限的断点中，依次比较 **① 最大行长最小 → ② 两行长度差最小 → ③ 断点最靠前**（左侧文字最短）。
5. 侧栏顶部汇总区间条数、可行 / 不可行条数与待写入条数；下方逐条展示**原文与重排结果**（含每行字素数、一行 / 两行标记），点击任意条目可跳转定位。
6. **无可行方案的条目标出具体原因**（如「单行已有 N 个字素，且不存在两行均不超限的断点」「所有等长断点都会使行首出现闭合标点或行尾出现起始标点」等），**该条不会被修改、也不能勾选**；已是最优排版（文本无变化）的条目标记为「无需调整」且不写入。
7. 用每条左侧的勾选框（或顶部 **全选**）只挑需要的可行项，点 **应用重排** 后仅写入勾选条目，其余字幕（含无可行方案者）原样保留；整批作为**一次撤销/重做**操作（`Ctrl/Cmd+Z` 即可整体回退）。重新导入字幕会自动重置区间与参数。

### 音频波形轨道

- 解码完全在浏览器内进行（Web Audio API `decodeAudioData`），文件不经过任何服务器；解码期间波形轨道显示忙碌动画。
- 波形按固定时间桶（10ms，超长音频自动增大桶长以控制内存）统计每个桶的正/负峰值，与刻度、字幕块、播放头共用同一时间坐标（`秒 × 缩放`），拖动缩放滑块或横向滚动时仅重绘可视区。
- 若文件无音轨、格式不受支持或解码失败，波形轨道内会显示可关闭的提示，字幕编辑不受影响；重新 **导入视频** 即可重试。
- 波形数据只保存在内存中，切换视频时自动释放旧数据（峰值数组随状态替换回收，解码用 `AudioContext` 即完即关）。
